# Expense Tracker (Трекер расходов)

**Автор:** [Ваше Имя и Фамилия]

## Описание
Простое GUI-приложение для учета личных финансов. Позволяет добавлять расходы, указывать категории и даты, а также фильтровать данные с автоматическим пересчетом итоговой суммы.

## Функционал
- Сохранение данных в формате JSON.
- Валидация ввода (сумма должна быть числом > 0, дата в формате YYYY-MM-DD).
- Фильтрация по категориям.
- Динамический подсчет общей суммы за выбранный период/категорию.

## Как использовать
1. Установите Python 3.x.
2. Запустите скрипт: `python expense_tracker.py`.
3. Введите сумму, выберите категорию из списка и нажмите «Добавить расход».
4. Для фильтрации выберите нужную категорию в выпадающем списке и нажмите «Применить».

## Примеры использования
- **Тест 1**: Ввод суммы "-50" приведет к ошибке валидации.
- **Тест 2**: Ввод даты "32.12.2023" приведет к ошибке формата.
- **Тест 3**: После добавления двух покупок по 500 и 300 руб., поле "Итого" покажет 800.00.
